Impera Meta MCP __VERSAO__

A ponte do Claude com a Meta Ads, com um token por cliente.

Este instalador:

  • coloca o app Impera Meta MCP na pasta Aplicativos;
  • prepara um Python só para o app (pela internet, leva de 1 a 3 minutos);
  • liga o servidor meta-ads ao Claude Desktop;
  • abre o app no fim.

Se o app já estiver instalado, ele é atualizado. Clientes, tokens, permissões e relatórios ficam como estão.

O macOS pede a senha do Mac para concluir. Deixe o Mac conectado à internet durante a instalação.
